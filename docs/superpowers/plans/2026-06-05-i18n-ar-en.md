# Bilingual (EN / AR) Internationalization — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add English (`en`, LTR) and Arabic (`ar`, RTL) across the public site, CMS content, and admin panel, with locale-prefixed routing (`/en`, `/ar`) and a language switcher button.

**Architecture:** Use **next-intl** with `localePrefix: "always"`. All page routes move under an `app/[locale]/` segment; API routes stay at the app root. A single `middleware.ts` composes next-intl's locale middleware with the existing Auth.js (NextAuth v5) middleware. CMS models gain nullable Arabic sibling columns; a `pickLocalized()` helper resolves fields with English fallback. UI strings live in `messages/{en,ar}.json`.

**Tech Stack:** Next.js 16.2.7 (App Router), next-intl (v4), NextAuth v5 beta, Prisma 7 (PostgreSQL), Tailwind CSS v4, TypeScript, vitest (new, for one helper).

**Reference spec:** `docs/superpowers/specs/2026-06-05-i18n-ar-en-design.md`

**Important environment notes:**
- Shell is PowerShell. Commands below use PowerShell syntax. For `git mv` and `npx`, syntax is identical.
- The Prisma client is vendored (`@prisma/client` → `file:vendor\prisma-client-7.8.0.tgz`); after schema changes run `npm run db:generate`.
- `src/app/(site)` route group uses `export const dynamic = "force-dynamic"`; static-rendering APIs (`setRequestLocale`) are still included for correctness but are not load-bearing here.
- There is **no test harness today**. This plan adds vitest solely for `pickLocalized()`. Everything else is verified with `npx tsc --noEmit`, `npm run build`, and manual checks via `npm run dev`.

- [ ] **Step 3: Create `src/i18n/request.ts`** (loads the locale's messages, deep-merged over English so missing Arabic keys fall back to English)

```typescript
import { getRequestConfig } from "next-intl/server";
import { hasLocale } from "next-intl";
import { routing } from "./routing";
import en from "../../messages/en.json";

type Messages = typeof en;

// Deep-merge locale messages over the English base so any missing key
// falls back to English rather than rendering the raw key.
function deepMerge<T>(base: T, override: Partial<T>): T {
  const out = { ...base } as Record<string, unknown>;
  for (const key of Object.keys(override as object)) {
    const b = (base as Record<string, unknown>)[key];
    const o = (override as Record<string, unknown>)[key];
    out[key] =
      b && o && typeof b === "object" && typeof o === "object"
        ? deepMerge(b, o as object)
        : o;
  }
  return out as T;
}

export default getRequestConfig(async ({ requestLocale }) => {
  const requested = await requestLocale;
  const locale = hasLocale(routing.locales, requested)
    ? requested
    : routing.defaultLocale;

  const messages =
    locale === routing.defaultLocale
      ? en
      : deepMerge(
          en,
          (await import(`../../messages/${locale}.json`)).default as Partial<Messages>,
        );

  return { locale, messages };
});
```

    authorized({ auth, request: { nextUrl } }) {
      const isLoggedIn = !!auth?.user;
      // Strip a leading /en or /ar so checks work under locale prefixes.
      const path = nextUrl.pathname.replace(/^\/(en|ar)(?=\/|$)/, "") || "/";
      const isOnAdmin = path.startsWith("/admin");
      const isOnLogin = path === "/admin/login";

      if (isOnLogin) return true; // login page always reachable
      if (isOnAdmin) return isLoggedIn; // gate the rest of /admin
      return true;

```typescript
import type { Locale } from "@/i18n/routing";

/**
 * Resolve a localized value: returns the Arabic value when the locale is `ar`
 * and the Arabic value is "present", otherwise the English/default value.
 *
 * "Present" means: non-null, and — for strings — non-empty after trimming.
 * Non-string values (e.g. Tiptap JSON) count as present when not null/undefined.
 */
export function pickLocalized<T>(en: T, ar: T | null | undefined, locale: Locale | string): T {
  if (locale !== "ar") return en;
  if (ar === null || ar === undefined) return en;
  if (typeof ar === "string" && ar.trim() === "") return en;
  return ar;
}
```

  return {
    ...p,
    title: pickLocalized(p.title, p.titleAr, locale),
    excerpt: pickLocalized(p.excerpt, p.excerptAr, locale),
